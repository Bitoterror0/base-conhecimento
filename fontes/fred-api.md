- ID: `fred-api`
- Assunto: financas-e-economia
- Cobertura: Estados Unidos / séries globais
- Página lida: 2026-10-04
- Fonte primária: https://fred.stlouisfed.org/docs/api/fred/

Índice oficial de endpoints para séries, observações, lançamentos, datas de atualização e vintages. Distingue a versão 1, adequada a consultas seletivas, da versão 2, orientada a recuperação ampla por lançamento. ALFRED permite estudar o que estava disponível em datas anteriores.

## Consulta e atualização

- Acesso: API documentada; versão 1 exige chave pessoal conforme página de autenticação catalogada separadamente.
- Formatos: API; formato definido pela documentação de cada endpoint
- API: https://api.stlouisfed.org/fred/
- Estado: Documentada; não executada por esta curadoria
- Revisão: Consultar calendário de lançamentos, series/updates e vintages. Armazenar série, unidade, frequência e período de coleta.
- Licença: não verificada; consultar termos
