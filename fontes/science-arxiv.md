# arXiv — API e repositório de manuscritos

- ID: `science-arxiv`
- Assunto: tecnologia-e-ciencia
- Cobertura: global
- Página lida: 2026-10-04
- Fonte primária: https://info.arxiv.org/help/api/basics.html
- Palavras-chave: IA, ciência de dados, pesquisa, preprints, metadados

Documentação oficial de acesso programático ao arXiv, repositório de manuscritos muito usado em física, matemática e computação. A API permite pesquisar e recuperar metadados em Atom XML, com título, autores, resumo, identificadores e links. É útil para descobrir estudos de IA e ciência de dados sem baixar todo o acervo. Manuscritos podem anteceder a publicação ou nunca ser publicados em periódicos; registrar versão, DOI e situação de revisão ajuda a separar descoberta de evidência consolidada.

## Consulta e atualização

- Acesso: Repositório de leitura aberta e API pública, sujeitos aos termos de uso oficiais.
- Formatos: HTML, Atom 1.0 / XML, PDF dos manuscritos vinculados
- API: http://export.arxiv.org/api/query
- Estado: Documentada; não executada por esta curadoria
- Revisão: Sugerido: busca semanal por categorias relevantes; conferir nova versão e eventual publicação quando um estudo embasar decisão.
- Licença: Não presumida: conferir termos específicos da fonte/dataset antes de redistribuir conteúdo.

## Cuidados

- Preprint não comprova revisão por pares; verificar situação de cada manuscrito.
- Respeitar termos de API e limites antes de automatizar.
- Licença de reutilização deve ser verificada por artigo; não assumir licença única para todo o acervo.
