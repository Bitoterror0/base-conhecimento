# BIS — portal de estatísticas / exportação

- ID: `bis-export`
- Assunto: financas-e-economia
- Cobertura: Global
- Página lida: 2026-10-04
- Fonte primária: https://data.bis.org/help/export
- Palavras-chave: estatísticas financeiras, séries internacionais, SDMX, metadados

Guia de exportação de dados e metadados do BIS. Oferece seleção de séries, CSV, Excel e SDMX, além de geração de trechos de consulta para a API REST. A seleção de até 4.500 séries é descrita, mas o catálogo proposto deve recuperar somente séries necessárias.

## Consulta e atualização

- Acesso: Exportação pública condicionada aos termos e à citação; API documentada por link na página.
- Formatos: CSV, Excel, SDMX, ZIP, PDF para tabelas específicas

- Estado: Sem endpoint de coleta confirmado neste cartão
