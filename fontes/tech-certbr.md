# CERT.br — estatísticas de segurança

- ID: `tech-certbr`
- Assunto: tecnologia-e-ciencia
- Cobertura: Brasil
- Página lida: 2026-10-04
- Fonte primária: https://stats.cert.br/
- Palavras-chave: cibersegurança, incidentes, phishing, spam, DDoS

Portal mantido pelo CERT.br/NIC.br com estatísticas de incidentes reportados, phishing, servidores DNS maliciosos, serviços vulneráveis, amplificadores, indícios de comprometimento, tráfego contra honeypots e spam. É útil para acompanhar os tipos de sinais observados na Internet brasileira e selecionar séries para estudos de segurança. A própria descrição distingue notificações voluntárias e observações de infraestrutura monitorada. Nas análises, registrar a série e o universo observado para evitar extrapolar os dados para todos os ataques do país.
