# Ministério da Saúde — Portal de Dados Abertos do SUS

- ID: `sus-dados-abertos`
- Assunto: saude
- Cobertura: Brasil
- Página lida: 2026-10-04
- Fonte primária: https://dadosabertos.saude.gov.br/
- Palavras-chave: dados abertos, arboviroses, atenção primária, assistência

O endereço OpenDataSUS consultado redirecionou para o Portal de Dados Abertos do SUS. A página apresenta conjuntos por temas, incluindo arboviroses, assistência, atenção primária e diagnósticos, e liga uma API de dados abertos e planos institucionais. É uma entrada reutilizável para encontrar conjuntos e sua documentação, sem pressupor disponibilidade imediata de todas as bases planejadas. O portal exibe o PDA 2026–2028; esse período é de planejamento, não de referência de cada observação nem comprovação de atualização diária dos dados.
